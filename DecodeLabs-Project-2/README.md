# DecodeLabs Project 2 — Exploratory Data Analysis

## Objective
Analyze the provided dataset to understand patterns, trends, distributions, and outliers.

## Requirements covered
- Basic statistics: count, mean, median
- Descriptive statistics
- Outlier identification using the 1.5 × IQR rule
- Distribution visualization
- Key observations

## Tools
Python, Pandas, NumPy, Matplotlib, Jupyter Notebook.

## Project Structure
- `data/raw/` — original dataset
- `data/cleaned/` — cleaned dataset
- `src/` — analysis script
- `notebooks/` — EDA notebook
- `outputs/` — generated statistics and findings
- `reports/` — final project report
